\# YAS Downloader



\## 🇮🇷 فارسی



YAS Downloader یک دانلود منیجر مدرن برای ویندوز است که با هدف ایجاد تجربه‌ای سریع، ساده و زیبا برای مدیریت دانلودها ساخته شده است.



این پروژه با تمرکز روی سرعت، رابط کاربری مدرن و اتصال آسان به مرورگر طراحی شده است.



\---



\## ✨ امکانات نسخه 1.0.0



\- ✅ دانلود چنداتصاله (Multi-Connection Download) برای افزایش سرعت

\- ✅ توقف و ادامه دانلودها (Pause / Resume)

\- ✅ مدیریت صف دانلودها

\- ✅ اتصال به مرورگر از طریق Extension

\- ✅ ارتباط امن بین مرورگر و برنامه با Native Messaging

\- ✅ رابط کاربری مدرن ساخته شده با Electron و React



\---



\## 📥 نصب برنامه



1\. فایل نصب زیر را دانلود کنید:



```

YAS Downloader Setup 1.0.0.exe

```



2\. برنامه را نصب کنید.



3\. برای اتصال مرورگر، Extension مرورگر را نصب کنید.



\---



\## 🌐 نصب Extension مرورگر



برای فعال‌سازی اتصال مرورگر:



1\. وارد صفحه Extensions مرورگر شوید:



```

chrome://extensions

```



2\. گزینه زیر را فعال کنید:



```

Developer Mode

```



3\. روی گزینه زیر کلیک کنید:



```

Load unpacked

```



4\. پوشه زیر را انتخاب کنید:



```

extension

```



5\. بعد از نصب، روی لینک دانلود راست کلیک کنید و گزینه زیر را انتخاب کنید:



```

Download with YAS Downloader

```

\# 🇬🇧 English



YAS Downloader is a modern download manager for Windows designed to provide a fast, simple and beautiful download experience.



The project focuses on download speed, modern user interface and easy browser integration.



\---



\## ✨ Features (v1.0.0)



\- ✅ Multi-connection download engine

\- ✅ Pause and Resume downloads

\- ✅ Download queue management

\- ✅ Browser integration through Extension

\- ✅ Secure communication using Native Messaging

\- ✅ Modern desktop interface built with Electron and React



\---



\## 📥 Installation



1\. Download the installer:



```

YAS Downloader Setup 1.0.0.exe

```



2\. Install the application.



3\. Install the browser extension to enable browser integration.



\---



\## 🌐 Browser Extension Setup



To connect your browser:



1\. Open the extensions page:



```

chrome://extensions

```



2\. Enable:



```

Developer Mode

```



3\. Click:



```

Load unpacked

```



4\. Select the:



```

extension

```



folder.



5\. Right-click any download link and choose:



```

Download with YAS Downloader

```
